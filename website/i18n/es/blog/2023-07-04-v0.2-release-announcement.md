Las [Collections](/rest/api/Collection) permiten extender fácilmente Arrays y Objects
agregando nuevos miembros con [push](/rest/api/Collection#push) o [unshift](/rest/api/Collection#unshift).
El nombre proviene de las [Collections de Backbone](https://backbonejs.org/#Collection).

Las [Collections](/rest/api/Collection) son ahora el schema predeterminado de [Resource.getList](/rest/api/resource#getlist).

import { Entity } from '@data-client/rest';
import { createResource } from '@data-client/rest';

export class Todo extends Entity {
  id = 0;
  userId = 0;
  title = '';
  completed = false;
  pk() {
    return `${this.id}`;
  }
  static key = 'Todo';
}
export const TodoResource = createResource({
  urlPrefix: 'https://jsonplaceholder.typicode.com',
  path: '/todos/:id',
  searchParams: {} as { userId?: string | number } | undefined,
  schema: Todo,
  optimistic: true,
});

```tsx title="TodoItem" {7-11,13-15} collapsed
import { useController } from '@data-client/react';
import { TodoResource, type Todo } from './TodoResource';

export default function TodoItem({ todo }: { todo: Todo }) {
  const ctrl = useController();
  const handleChange = e =>
    ctrl.fetch(
      TodoResource.partialUpdate,
      { id: todo.id },
      { completed: e.currentTarget.checked },
    );
  const handleDelete = () =>
    ctrl.fetch(TodoResource.delete, {
      id: todo.id,
    });
  return (
    <div className="listItem nogap">
      <label>
        <input
          type="checkbox"
          checked={todo.completed}
          onChange={handleChange}
        />
        {todo.completed ? <strike>{todo.title}</strike> : todo.title}
      </label>
      <CancelButton onClick={handleDelete} />
    </div>
  );
}
```

```tsx title="CreateTodo" {8-12}
import { useController } from '@data-client/react';
import { TodoResource } from './TodoResource';

export default function CreateTodo({ userId }: { userId: number }) {
  const ctrl = useController();
  const handleKeyDown = async e => {
    if (e.key === 'Enter') {
      ctrl.fetch(TodoResource.getList.push, {
        userId,
        title: e.currentTarget.value,
        id: Math.random(),
      });
      e.currentTarget.value = '';
    }
  };
  return (
    <div className="listItem nogap">
      <label>
        <input type="checkbox" name="new" checked={false} disabled />
        <input type="text" onKeyDown={handleKeyDown} />
      </label>
    </div>
  );
}
```

import { useSuspense } from '@data-client/react';
import { TodoResource } from './TodoResource';

function TodoList() {
  const userId = 1;

  return (

    </div>
  );
}
render(<TodoList />);

Actualizar es bastante sencillo, ya que se introdujeron `@data-client/rest/next` y `@data-client/react/next`
para permitir la adopción incremental de las nuevas APIs que cambian en esta versión. Esto convierte la actualización en sí en un simple
cambio de nombre en los imports.

Otros aspectos destacados incluyen

- `@data-client/rest`
  - [RestEndpoint.getHeaders asíncrono](https://github.com/reactive/data-client/pull/2542)
- `@data-client/react`
  - [El valor de retorno de Controller.fetch() se desnormaliza a partir del schema](https://github.com/reactive/data-client/pull/2545)
  - [Actualizaciones de los tipos de acción de Manager](https://github.com/reactive/data-client/pull/2690)

Para todos los detalles, [sigue leyendo](/blog/2023/07/04/v0.2-release-announcement#data-clientreact-02):

#### Cambios {#changes}

- **Controller.fetch()**: [2545](https://github.com/reactive/data-client/pull/2545) Controller.fetch() devuelve la forma desnormalizada cuando el Endpoint tiene un Schema
  ```ts
  const handleChange = async e => {
    const todo = await ctrl.fetch(
      TodoResource.partialUpdate,
      { id: todo.id },
      { completed: e.currentTarget.checked },
    );
    // todo is Todo, we can use all its members and be type-safe
    console.log(todo.pk(), todo.title);
  };
  ```

- **NetworkManager**: La interfaz de NetworkManager cambió para admitir solo las nuevas acciones [2690](https://github.com/reactive/data-client/pull/2690)
- Las interfaces de **SubscriptionManager/PollingSubscription** se simplificaron con base en las nuevas acciones [2690](https://github.com/reactive/data-client/pull/2690)

#### Eliminación de elementos obsoletos {#removals-of-deprecated-items}

- [2691](https://github.com/reactive/data-client/pull/2691): Se eliminan DispatchContext y DenormalizeCacheContext

#### Deprecaciones {#deprecations}

- controller.receive, controller.receiveError [2690](https://github.com/reactive/data-client/pull/2690)
- RECEIVE_TYPE [2690](https://github.com/reactive/data-client/pull/2690)
- MiddlewareAPI.controller (MiddlewareAPI es simplemente el propio controller) [2690](https://github.com/reactive/data-client/pull/2690)
  - `({controller}) => {}` -> `(controller) => {}`

#### Cambios {#changes-1}

- getRequestInit y getHeaders de RestEndpoint pueden devolver opcionalmente una promesa [2542](https://github.com/reactive/data-client/pull/2542)

  ```ts
  import { RestEndpoint } from '@data-client/rest/next';

  export default class AuthdEndpoint<
    O extends RestGenerics = any,
  > extends RestEndpoint<O> {
    declare static accessToken?: string;

    async getHeaders(headers: HeadersInit) {
      return {
        ...headers,
        'Access-Token': await getOrFetchToken(),
      } as HeadersInit;
    }
  }

  export const TodoResource = createResource({
    urlPrefix: 'https://jsonplaceholder.typicode.com',
    path: '/todos/:id',
    schema: Todo,
    Endpoint: AuthdEndpoint,
  });
  ```

  BREAKING: Llamar a super.getRequestInit() devolverá una promesa, así que debes resolverla:

<DiffEditor>

```ts title="Before"
class AuthdEndpoint<
  O extends RestGenerics = any,
> extends RestEndpoint<O> {
  getRequestInit(body: any): RequestInit {
    return {
      ...super.getRequestInit(body),
      credentials: 'same-origin',
    };
  }
}
```

```ts title="After"
class AuthdEndpoint<
  O extends RestGenerics = any,
> extends RestEndpoint<O> {
  async getRequestInit(body: any): Promise<RequestInit> {
    return {
      ...(await super.getRequestInit(body)),
      credentials: 'same-origin',
    };
  }
}
```

</DiffEditor>

- createResource().getList usa una Collection, a la que .create agrega elementos [2593](https://github.com/reactive/data-client/pull/2593)
  - `Resource.create` agregará automáticamente a la lista
    - `Resource.getList.push` es idéntico a `Resource.create`
  - **Elimina** cualquier `Endpoint.update`, ya que no es necesario y no funcionará
- Los parámetros de `GetEndpoint` y `MutateEndpoint` cambiaron a lo que eran `NewGetEndpoint` y `NewMutateEndpoint`.
- Los genéricos de createResource() cambiaron a `O extends ResourceGenerics`. Esto permite personalizar el tipo del Resource con body y searchParams [2593](https://github.com/reactive/data-client/pull/2593)
  - `createGithubResource<U extends string, S extends Schema>` -> `createGithubResource<O extends ResourceGenerics>`

[PR #2692 que incorpora /next al nivel superior](https://github.com/reactive/data-client/pull/2692)

#### Eliminación de elementos obsoletos {#removals-of-deprecated-items-1}

- [2690](https://github.com/reactive/data-client/pull/2690): Se elimina el obsoleto `Endpoint.optimisticUpdate` -> usa `Endpoint.getOptimisticResponse`
- [2688](https://github.com/reactive/data-client/pull/2688) Se elimina la compatibilidad con `FetchShape`.
