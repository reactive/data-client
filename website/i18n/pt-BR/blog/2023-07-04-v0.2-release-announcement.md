[Collections](/rest/api/Collection) permitem estender Arrays e Objects com facilidade
fazendo [push](/rest/api/Collection#push) ou [unshift](/rest/api/Collection#unshift) de novos
membros. O nome vem das [Collections do Backbone](https://backbonejs.org/#Collection).

[Collections](/rest/api/Collection) agora são o schema padrão de [Resource.getList](/rest/api/resource#getlist).

```ts title="TodoResource" collapsed
import { Entity } from '@data-client/rest';
import { createResource } from '@data-client/rest';

export class Todo extends Entity {
  id = 0;
  userId = 0;
  title = '';
  completed = false;
  pk() {
    return `${this.id}`;
  }
  static key = 'Todo';
}
export const TodoResource = createResource({
  urlPrefix: 'https://jsonplaceholder.typicode.com',
  path: '/todos/:id',
  searchParams: {} as { userId?: string | number } | undefined,
  schema: Todo,
  optimistic: true,
});
```

```tsx title="TodoItem" {7-11,13-15} collapsed
import { useController } from '@data-client/react';
import { TodoResource, type Todo } from './TodoResource';

export default function TodoItem({ todo }: { todo: Todo }) {
  const ctrl = useController();
  const handleChange = e =>
    ctrl.fetch(
      TodoResource.partialUpdate,
      { id: todo.id },
      { completed: e.currentTarget.checked },
    );
  const handleDelete = () =>
    ctrl.fetch(TodoResource.delete, {
      id: todo.id,
    });
  return (
    <div className="listItem nogap">
      <label>
        <input
          type="checkbox"
          checked={todo.completed}
          onChange={handleChange}
        />
        {todo.completed ? <strike>{todo.title}</strike> : todo.title}
      </label>
      <CancelButton onClick={handleDelete} />
    </div>
  );
}
```

```tsx title="CreateTodo" {8-12}
import { useController } from '@data-client/react';
import { TodoResource } from './TodoResource';

export default function CreateTodo({ userId }: { userId: number }) {
  const ctrl = useController();
  const handleKeyDown = async e => {
    if (e.key === 'Enter') {
      ctrl.fetch(TodoResource.getList.push, {
        userId,
        title: e.currentTarget.value,
        id: Math.random(),
      });
      e.currentTarget.value = '';
    }
  };
  return (
    <div className="listItem nogap">
      <label>
        <input type="checkbox" name="new" checked={false} disabled />
        <input type="text" onKeyDown={handleKeyDown} />
      </label>
    </div>
  );
}
```

```tsx title="TodoList" collapsed
import { useSuspense } from '@data-client/react';
import { TodoResource } from './TodoResource';
import TodoItem from './TodoItem';
import CreateTodo from './CreateTodo';

function TodoList() {
  const userId = 1;
  const todos = useSuspense(TodoResource.getList, { userId });
  return (
    <div>
      {todos.map(todo => (
        <TodoItem key={todo.pk()} todo={todo} />
      ))}
      <CreateTodo userId={userId} />
    </div>
  );
}
render(<TodoList />);
```

Atualizar é bem simples, pois `@data-client/rest/next` e `@data-client/react/next` foram introduzidos
para permitir a adoção incremental das novas APIs alteradas neste lançamento. Isso torna a atualização em si uma simples
renomeação de imports.

Outros destaques incluem

- `@data-client/rest`
  - [RestEndpoint.getHeaders assíncrono](https://github.com/reactive/data-client/pull/2542)
- `@data-client/react`
  - [O valor de retorno de Controller.fetch() é desnormalizado a partir do schema](https://github.com/reactive/data-client/pull/2545)
  - [Atualizações nos tipos de ação dos Managers](https://github.com/reactive/data-client/pull/2690)


#### Mudanças {#changes}

- **Controller.fetch()**: [2545](https://github.com/reactive/data-client/pull/2545) Controller.fetch() retorna a forma desnormalizada quando o Endpoint tem um Schema
  ```ts
  const handleChange = async e => {
    const todo = await ctrl.fetch(
      TodoResource.partialUpdate,
      { id: todo.id },
      { completed: e.currentTarget.checked },
    );
    // todo is Todo, we can use all its members and be type-safe
    console.log(todo.pk(), todo.title);
  };
  ```

- **NetworkManager**: a interface do NetworkManager mudou para suportar apenas as novas ações [2690](https://github.com/reactive/data-client/pull/2690)
- Interfaces de **SubscriptionManager/PollingSubscription** simplificadas com base nas novas ações [2690](https://github.com/reactive/data-client/pull/2690)

#### Remoções de itens descontinuados {#removals-of-deprecated-items}

- [2691](https://github.com/reactive/data-client/pull/2691): Remove DispatchContext, DenormalizeCacheContext

#### Descontinuações {#deprecations}

- controller.receive, controller.receiveError [2690](https://github.com/reactive/data-client/pull/2690)
- RECEIVE_TYPE [2690](https://github.com/reactive/data-client/pull/2690)
- MiddlewareAPI.controller (MiddlewareAPI é simplesmente o próprio controller) [2690](https://github.com/reactive/data-client/pull/2690)
  - `({controller}) => {}` -> `(controller) => {}`

#### Mudanças {#changes-1}

- getRequestInit e getHeaders do RestEndpoint podem opcionalmente retornar uma promise [2542](https://github.com/reactive/data-client/pull/2542)

  ```ts
  import { RestEndpoint } from '@data-client/rest/next';

  export default class AuthdEndpoint<
    O extends RestGenerics = any,
  > extends RestEndpoint<O> {
    declare static accessToken?: string;

    async getHeaders(headers: HeadersInit) {
      return {
        ...headers,
        'Access-Token': await getOrFetchToken(),
      } as HeadersInit;
    }
  }

  export const TodoResource = createResource({
    urlPrefix: 'https://jsonplaceholder.typicode.com',
    path: '/todos/:id',
    schema: Todo,
    Endpoint: AuthdEndpoint,
  });
  ```

  BREAKING: Chamar super.getRequestInit() retornará uma promise - então você precisa resolvê-la:

<DiffEditor>

```ts title="Before"
class AuthdEndpoint<
  O extends RestGenerics = any,
> extends RestEndpoint<O> {
  getRequestInit(body: any): RequestInit {
    return {
      ...super.getRequestInit(body),
      credentials: 'same-origin',
    };
  }
}
```

```ts title="After"
class AuthdEndpoint<
  O extends RestGenerics = any,
> extends RestEndpoint<O> {
  async getRequestInit(body: any): Promise<RequestInit> {
    return {
      ...(await super.getRequestInit(body)),
      credentials: 'same-origin',
    };
  }
}
```

</DiffEditor>

- createResource().getList usa uma Collection, à qual .create adiciona ao final [2593](https://github.com/reactive/data-client/pull/2593)
  - `Resource.create` adicionará automaticamente à lista
    - `Resource.getList.push` é idêntico a `Resource.create`
  - **Remova** qualquer `Endpoint.update`, pois não é necessário e não funcionará
- Os parâmetros de `GetEndpoint` e `MutateEndpoint` mudaram para o que eram `NewGetEndpoint` e `NewMutateEndpoint`.
- Os genéricos de createResource() mudaram para `O extends ResourceGenerics`. Isso permite personalizar o tipo do Resource com body e searchParams [2593](https://github.com/reactive/data-client/pull/2593)
  - `createGithubResource<U extends string, S extends Schema>` -> `createGithubResource<O extends ResourceGenerics>`

[PR #2692 que promove o /next](https://github.com/reactive/data-client/pull/2692)

- [2690](https://github.com/reactive/data-client/pull/2690): Removido o descontinuado `Endpoint.optimisticUpdate` -> use `Endpoint.getOptimisticResponse`
- [2688](https://github.com/reactive/data-client/pull/2688) Remove a compatibilidade com `FetchShape`.
