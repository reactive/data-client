## Resource.extend() <small>（自 0.5 起）</small> {#resourceextend}

[Resource.extend()](/rest/api/resource#extend) 提供了三种强大的方式来自定义 resource。
[51b4b0d](https://github.com/reactive/data-client/commit/51b4b0d188)

### 添加新的 endpoint {#add-new-endpoints}

```ts
const UserResource = createResource({
  path: '/users/:id',
  schema: User,
}).extend('current', {
  path: '/users/current',
});
```

### 覆盖已有的 endpoint {#override-existing-endpoints}

```ts
const CachedArticleResource = ArticleResource.extend({
  getList: {
    dataExpiryLength: 10 * 60 * 1000, // 10 minutes
  },
});
```

### 从基础 endpoint 派生 {#derive-from-base-endpoints}

```ts
const IssueResource = createResource({
  path: '/issues/:id',
  schema: Issue,
}).extend(Base => ({
  byRepo: Base.getList.extend({
    path: '/repos/:owner/:repo/issues',
  }),
}));
```

## Controller 方法 {#controller-methods}

### controller.expireAll() <small>（自 0.3 起）</small> {#controllerexpireall}

将所有匹配的响应标记为*过时*，在继续显示现有数据的同时触发后台重新获取。
[#2802](https://github.com/reactive/data-client/pull/2802)

```ts
// Mark all article lists as stale - they'll refetch when rendered
controller.expireAll(ArticleResource.getList);
```

这与会完全移除数据的 `invalidateAll()` 不同。`expireAll()` 会继续显示
缓存的数据，同时在后台获取最新数据。

### controller.fetchIfStale() <small>（自 0.4 起）</small> {#controllerfetchifstale}

仅在数据被视为过时时才发起获取；否则返回缓存的数据。
[#2804](https://github.com/reactive/data-client/pull/2804)

```ts
// Perfect for prefetching - won't overfetch fresh data
const resolveData = async (controller, { owner, repo }) => {
  await controller.fetchIfStale(IssueResource.getList, { owner, repo });
};
```

## DevTools 改进 {#devtools-improvements}

### DevTools 按钮 {#devtools-button}

开发模式下现在会显示一个浮动按钮，用于快速打开 Redux DevTools 扩展。
[#2803](https://github.com/reactive/data-client/pull/2803)

通过 `devButton` prop 配置或禁用它：

```tsx
// Disable the button
<CacheProvider devButton={null}>
  <App />
</CacheProvider>
```

```tsx
// Position it differently
<CacheProvider devButton="top-right">
  <App />
</CacheProvider>
```

### 持久化的历史记录 {#persistent-history}

即使页面加载时 DevTools 未打开，也不再丢失历史记录。
[2d2e941](https://github.com/reactive/data-client/commit/2d2e94126e)

### 更好的状态跟踪 {#better-state-tracking}

由于 React 18 会对更新进行批处理，真实状态有时会由多个 action 一起更新。
当 devtools 打开时，一个影子状态会准确反映每个 action 带来的变化，便于调试。
[c9ca31f](https://github.com/reactive/data-client/commit/c9ca31f3f4)

### Endpoint 属性可见 {#endpoint-properties-visible}

Endpoint 的属性现在可以在 devtool 检查器中完整查看。
[a7da00e](https://github.com/reactive/data-client/commit/a7da00e82d)

## Collection 增强 {#collection-enhancements}

### FormData 参数筛选 <small>（自 0.4 起）</small> {#formdataargumentfiltering}

[Collection](/rest/api/Collection) 现在可以基于 FormData 参数进行筛选。[f95dbc6](https://github.com/reactive/data-client/commit/f95dbc64d1)

```ts
ctrl.fetch(getPosts.push, { group: 'react' }, new FormData(e.currentTarget));
```

如果 FormData 中包含 `author` 字段，新创建的条目会被正确地添加到
按该作者筛选的 collection 中。

### paginationField <small>（自 0.7 起）</small> {#paginationfield}

使用 [paginationField](/rest/api/RestEndpoint#paginationfield) 轻松支持分页。
[c8c557](https://github.com/reactive/data-client/commit/c8c5575e5a)

```ts
const TodoResource = createResource({
  path: '/todos/:id',
  schema: Todo,
  paginationField: 'page',
});

// Fetches page 2 and appends to the collection
ctrl.fetch(TodoResource.getList.getPage, { page: '2' });
```

### 移除 /next 导出 {#remove-next-exports}

所有 `/next` 子路径导出都已移除。之前位于 `/next` 中的功能现在
是标准导出。[f65cf83](https://github.com/reactive/data-client/commit/f65cf832f0)

<DiffEditor>

```ts title="Before"
import { useController } from '@data-client/react/next';
```

```ts title="After"
import { useController } from '@data-client/react';
```

</DiffEditor>

### 移除 makeCacheProvider {#makecacheprovider-removed}

请直接把 provider 组件传给 makeRenderDataClient。
[#2787](https://github.com/reactive/data-client/pull/2787)

<DiffEditor>

```tsx title="Before"
import { makeCacheProvider } from '@data-client/react';
const renderDataClient = makeRenderDataClient(makeCacheProvider);
```

```tsx title="After"
import { CacheProvider } from '@data-client/react';
const renderDataClient = makeRenderDataClient(CacheProvider);
```

</DiffEditor>

### DELETE -> INVALIDATE action 类型 {#delete-invalidate}

为了更清晰，DELETE action 类型已重命名为 INVALIDATE。
[#2784](https://github.com/reactive/data-client/pull/2784)

<DiffEditor>

```ts title="Before"
import { DELETE_TYPE } from '@data-client/react';
```

```ts title="After"
import { INVALIDATE_TYPE } from '@data-client/react';
```

</DiffEditor>

### 不再支持遗留 schema {#legacy-schema-support-dropped}

对遗留 schema 的所有支持都已移除。请确保你使用的是当前的
Entity 类。[#2784](https://github.com/reactive/data-client/pull/2784)

- 移除了 `entity.expiresAt`
- 移除了所有为向后兼容而保留的 Entity 覆盖

### Schema 序列化器必须支持函数调用 {#schema-serializers}

[Schema 序列化器](/rest/guides/network-transform#deserializing-fields)现在必须支持
函数调用。`Date` 不再能直接使用。[#2795](https://github.com/reactive/data-client/pull/2795)

<DiffEditor>

```ts title="Before"
class MyEntity extends Entity {
  createdAt = new Date();

  static schema = {
    // highlight-next-line
    createdAt: Date,
  };
}
```

```ts title="After"
class MyEntity extends Entity {
  createdAt = new Date();

  static schema = {
    // highlight-next-line
    createdAt: (iso: string) => new Date(iso),
  };
}
```

</DiffEditor>

或者，使用 Temporal：

```ts
import { Temporal } from 'temporal-polyfill';

class MyEntity extends Entity {
  createdAt = Temporal.Instant.fromEpochSeconds(0);

  static schema = {
    createdAt: Temporal.Instant.from,
  };
}
```

### Action 类型加上 'rdc' 前缀 {#action-types-prefix}

为了更好的命名空间隔离，所有 action 类型现在都带有 'rdc' 前缀。
[#2781](https://github.com/reactive/data-client/pull/2781)

### receive -> set action 名称 {#receive---set-action-names}

所有 'receive' action 名称都已重命名为 'set'。
[#2782](https://github.com/reactive/data-client/pull/2782)

<DiffEditor>

```ts title="Before"
import { ReceiveAction, RECEIVE_TYPE } from '@data-client/react';
controller.receive(endpoint, args, response);
```

```ts title="After"
import { SetAction, SET_TYPE } from '@data-client/react';
controller.set(endpoint, args, response);
```

</DiffEditor>

### 简化的 Middleware API {#middleware-api-simplified}

Middleware 不再以解构属性的形式接收 `controller`，而是
直接接收 controller。[#2786](https://github.com/reactive/data-client/pull/2786)

<DiffEditor>

```ts title="Before"
class LoggingManager implements Manager {
  // highlight-next-line
  getMiddleware = (): Middleware => ({ controller }) => next => async action => {
    console.log('before', action, controller.getState());
    await next(action);
    console.log('after', action, controller.getState());
  };

  cleanup() {}
}
```

```ts title="After"
class LoggingManager implements Manager {
  // highlight-next-line
  getMiddleware = (): Middleware => controller => next => async action => {
    console.log('before', action, controller.getState());
    await next(action);
    console.log('after', action, controller.getState());
  };

  cleanup() {}
}
```

</DiffEditor>

### getDefaultManagers() {#getdefaultmanagers}

CacheProvider 元素不再共享默认的 manager。请使用 `getDefaultManagers()` 进行显式控制。
[#2791](https://github.com/reactive/data-client/pull/2791)

```ts
import { getDefaultManagers, CacheProvider } from '@data-client/react';

const managers = getDefaultManagers();

<CacheProvider managers={managers}>
  <App />
</CacheProvider>
```
