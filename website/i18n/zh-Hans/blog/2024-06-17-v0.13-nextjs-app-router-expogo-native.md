## 平台 {#platforms}

### NextJS App Router {#nextjs-app-router}

NextJS 12 引入了[在 '/app' 目录中进行路由的新方式](https://nextjs.org/docs/app)。它带来了进一步的性能提升，以及动态路由和嵌套路由。这使 NextJS 成为构建富动态应用的可行平台，
而不仅仅是静态网站。

[其他获取方式](https://nextjs.org/docs/app/building-your-application/data-fetching/fetching#fetching-data-on-the-client)
需要缓慢的客户端获取；而 Reactive Data Client 则兼具 <abbr title="单页应用">SPA</abbr> 和
<abbr title="多页应用">MPA</abbr> 两者的优点。[#3074](https://github.com/reactive/data-client/pull/3074)、[#3093](https://github.com/reactive/data-client/pull/3093)

与 MPA 一样，使用 Data Client 进行 SSR 意味着最快的*首次页面加载*。与 SPA 一样，Data Client 提供比 MPA 更快的
*导航*、*客户端变更*以及*远程驱动的变更*（例如 websocket）。

此外，搭配 SSR 的 Data Client 相比其他客户端
获取库依然保持性能优势。

<abbr title="Reactive Data Client">Data Client</abbr> 对 HTML 进行流式 SSR，优化了应用的
初始加载体验。独特之处在于，<abbr title="Reactive Data Client">Data Client</abbr> 随后立即可交互，
且客户端获取次数为 0。这是通过在 SSR 阶段用[规范化数据](/docs/concepts/normalization)初始化
[客户端 Store](/docs/getting-started/debugging#state-inspection) 来实现的。

#### 用法 {#usage}

在你的[根布局](https://nextjs.org/docs/app/building-your-application/routing/pages-and-layouts#root-layout-required)中渲染来自 [/nextjs 入口](https://dataclient.io/docs/guides/ssr#app-router)的 [DataProvider](/docs/api/DataProvider)。


```tsx title="app/layout.tsx"
import { DataProvider } from '@data-client/react/nextjs';
import { AsyncBoundary } from '@data-client/react';

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        // highlight-next-line
        <DataProvider>
          <header>Title</header>
          <AsyncBoundary>{children}</AsyncBoundary>
          <footer></footer>
          // highlight-next-line
        </DataProvider>
      </body>
    </html>
  );
}
```

## controller.set() {#controllerset}

[controller.set()](/docs/api/Controller#set) 可以更新任意 [Queryable](/rest/api/schema#queryable) [Schema](/rest/api/schema#schema-overview)。[#3105](https://github.com/reactive/data-client/pull/3105)、[#3129](https://github.com/reactive/data-client/pull/3129)

```ts
ctrl.set(
  Todo,
  { id: '5' },
  { id: '5', title: 'tell me friends how great Data Client is' },
);
```

当需要使用派生数据时，值可以是函数。这能[避免竞态条件](https://react.dev/reference/react/useState#updating-state-based-on-the-previous-state)。

```ts
const id = '2';
ctrl.set(Article, { id }, article => ({ id, votes: article.votes + 1 }));
```

:::note

响应必须包含足以计算 Entity.pk() 的值

:::

这让通过 [Manager](/docs/concepts/managers) 操作 store 变得更加直接。
例如，我们可以在收到 websocket 消息时直接设置 `Ticker` 实体：

## REST 变更 {#rest-changes}

### 路径字符串 {#path-strings}

[RestEndpoint.path](/rest/api/RestEndpoint#path) 支持 +、\* 和 \{}。[`a6b4f4a`](https://github.com/reactive/data-client/commit/a6b4f4aabbfd06f5106a96e809a6c1a5e7045172)

  ```ts
  const getThing = new RestEndpoint({
    path: '/:attr1?{-:attr2}?{-:attr3}?',
  });

  getThing({ attr1: 'hi' });
  getThing({ attr2: 'hi' });
  getThing({ attr3: 'hi' });
  getThing({ attr1: 'hi', attr3: 'ho' });
  getThing({ attr2: 'hi', attr3: 'ho' });
  ```

### ctrl.fetch() 与 Union {#ctrlfetch-and-unions}

[ctrl.fetch()](/docs/api/Controller#fetch) 返回值中的 [Union](/rest/api/Union) 值现在是其 Entity 类的实例。[#3063](https://github.com/reactive/data-client/pull/3063)

<TypeScriptEditor>

```ts title="Feed" collapsed
export abstract class FeedItem extends Entity {
  id = 0;
  declare type: 'link' | 'post';
}
export class Link extends FeedItem {
  readonly type = 'link';
  url = '';
  title = '';

  get anchor() {
    return `<a href="${this.url}">${this.title}</a>`;
  }
}
export class Post extends FeedItem {
  readonly type = 'post';
  content = '';
}
export const getFeed = new RestEndpoint({
  path: '/feed',
  schema: [new schema.Union(
    {
      link: Link,
      post: Post,
    },
    'type',
  )],
});
```

```ts title="useFeed"
import { getFeed } from './Feed';

function useFeedHandler() {
  const ctrl = useController();

  const handleSomething = async () => {
    const feed = await ctrl.fetch(getFeed);
    return feed.map(item => {
      if (item.type == 'link') {
        // we can use class defined getter
        return item.anchor;
      }
    });
  }
  return handleSomething;
}
```

</TypeScriptEditor>

### actionTypes.SET_TYPE -> actionTypes.SET_RESPONSE_TYPE {#set_response_type}

如果你编写了处理 `actionTypes.SET_TYPE` 的自定义 Manager，需要
将其重命名为 [actionTypes.SET_RESPONSE_TYPE](/docs/api/Actions#set_response)。

<DiffEditor>

```tsx title="Before"
import type { Manager, Middleware } from '@data-client/react';
import { actionTypes } from '@data-client/react';

export default class LoggingManager implements Manager {
  middleware: Middleware = controller => next => async action => {
    switch (action.type) {
      case actionTypes.SET_TYPE:
        console.info(
          `${action.endpoint.name} ${JSON.stringify(action.response)}`,
        );
        return next(action);
      // actions must be explicitly passed to next middleware
      default:
        return next(action);
    }
  };

  cleanup() {}
}
```

```tsx title="After"
import type { Manager, Middleware } from '@data-client/react';
import { actionTypes } from '@data-client/react';

export default class LoggingManager implements Manager {
  middleware: Middleware = controller => next => async action => {
    switch (action.type) {
      case actionTypes.SET_RESPONSE_TYPE:
        console.info(
          `${action.endpoint.name} ${JSON.stringify(action.response)}`,
        );
        return next(action);
      // actions must be explicitly passed to next middleware
      default:
        return next(action);
    }
  };

  cleanup() {}
}
```

</DiffEditor>

### CacheProvider -> DataProvider {#data-provider}

迁移到 [DataProvider](/docs/api/DataProvider) 以兼容未来版本。它同时也以
`CacheProvider` 的名称导出，因此这不是破坏性变更。[#3095](https://github.com/reactive/data-client/pull/3095)

<DiffEditor>

```tsx title="Before"
import { CacheProvider } from '@data-client/react';
import ReactDOM from 'react-dom';

ReactDOM.createRoot(document.body)
  .render(
  <CacheProvider>
    <App />
  </CacheProvider>,
);
```

```tsx title="Before"
import { DataProvider } from '@data-client/react';
import ReactDOM from 'react-dom';

ReactDOM.createRoot(document.body)
  .render(
  <DataProvider>
    <App />
  </DataProvider>,
);
```

</DiffEditor>
